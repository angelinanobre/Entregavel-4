# Entregável 4 — Testes Unitários com Jest

## Sobre o projeto

Este projeto tem como objetivo aplicar testes unitários aos algoritmos desenvolvidos no Entregável 1, utilizando o framework Jest.

Também foram realizadas melhorias na organização do código, na legibilidade e na validação das entradas, aplicando conceitos de programação defensiva.

## Algoritmos testados

- Número Primo
- Somatório
- Fibonacci
- MDC (Máximo Divisor Comum)
- Quicksort
- Contagem

## Tecnologias utilizadas

- JavaScript
- Node.js
- Jest

## Como executar o projeto

### 1. Instalar as dependências

No terminal, dentro da pasta do projeto, execute:

```bash
npm install
```

### 2. Executar os testes

Após a instalação, execute:

```bash
npm test
```

## Resultados dos testes

O projeto possui 24 testes unitários, distribuídos entre os seis algoritmos.

Todos os testes foram executados com sucesso:

- 6 suítes de testes aprovadas.
- 24 testes aprovados.
- 0 testes com falha.
